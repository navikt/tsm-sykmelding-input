# tsm-sykmeldinge-input

## Technologies used
* Kotlin
* Gradle

## Requirements for developing the lib
#### Java
Make sure you have the Java JDK 25 installed
You can check which version you have installed using this command:
``` bash
java -version
```
or install it: https://sdkman.io/

### Building the lib
To build the lib locally and run tests you can simply run
``` bash
./gradlew clean build
 ```


### Upgrading the Gradle wrapper version to latest
``` bash
./gradlew :wrapper --gradle-version latest
```
